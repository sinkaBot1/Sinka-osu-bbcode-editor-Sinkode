# 范围与已知限制

> 本文记录当前项目范围和已知限制。
> 兼容行为与差异的事实依据见[兼容性说明](compatibility.md)；测试与命令见[测试说明](testing.md)。
> 当前协作规则见[协作规则](../AGENTS.md)。

## 1. 范围与基准

- 当前功能范围包括编辑、补全、诊断、实时预览、模板与自动保存、复制、中文帮助、主题、桌面工作台布局和预览扫描线。
- 当前覆盖的 osu! 标签为 **24 / 24**；固定样例矩阵 **49 个 case**，完整性由 `node tests/check-osu-web-fixtures.mjs` 校验。
- 测试命令和完整的验证顺序见[测试说明](testing.md)。
- 锁定基准：osu-web `61b0a41431395f86ff68fa12744f3266448ec885`，正文最大宽度 `890px`。更换基准需由维护者确认并重跑全部固定样例。
- 在线站点已发布：<https://sinkodeosu.site/>（GitHub Pages + 自定义域名）；`https://osusinkode.top/` 只做跳转。
- 主题取值和令牌清单见[主题与切换动效](theme.md)。

## 2. 发布相关约定

- 改变站点公开范围、更换自定义域名、启用或关闭 GitHub Pages，需由维护者决定后执行。
- 自定义域名 `sinkodeosu.site` 与跳转域名 `osusinkode.top` 的 DNS 记录、续费与 HTTPS 证书由维护者维护。

## 3. 已知限制（保留现状，不作为缺陷处理）

| 限制 | 说明 |
| --- | --- |
| BBCode 导入导出 | 当前不提供 |
| 模板只存在本机 | 数据在浏览器 IndexedDB 中；清站点数据、无痕窗口或换设备都会丢失，且没有导出/导入 |
| Windows 剪贴板行为 | 系统可能规范化换行符；复制结果与编辑器原文的一致性以编辑器内原文为准 |
| 关闭页面瞬间的写入 | 关闭标签页时触发的异步 IndexedDB 写入不保证完成，最后几秒的修改可能丢失 |
| 构建体积 | 生产构建主脚本约 `571 kB`（gzip 约 `193 kB`），会触发超过 500 kB 的提示；未拆分 |
| 图片尺寸 | 上游显示阶段由服务端预取图片宽高；本项目只能由浏览器在加载后按原始宽高比与 `max-width: 100%` 缩放 |
| 无自动化跨浏览器矩阵 | 目前只在 Chromium 上跑端到端测试，其他浏览器靠人工验收 |
| 浅色主题的内嵌面 | Claucode 的 `--shell-inset-background` 与 `--color-surface` 同为 `#faf9f5`，帮助详情的详情块与写法框因此不产生面差，分区靠留白、微标签与轮廓；当前不做；如要单独加一档更暗的内嵌面，需维护者确认 |
| 界面令牌仍有迁移占位 | 详见 `src/app/scale.css` 末尾与 `npm run style:check` |
| 扫描线在画布留白处的对比度 | Claucode 下低于 `3:1` 图形参考线；已确认保持全宽，数值见[主题与切换动效](theme.md#6-对比度复核) |
| 指示行开启时的浅色语法对比度 | Claucode 整行染色会降低语法文字对比度，与当前行中性底同档；数值见[主题与切换动效](theme.md#6-对比度复核) |
| 扫描线的 8px 命中带 | 线体有 8px 透明命中带，会挡住该高度上一条薄层的预览点击，也会盖住预览滚动条在该高度的一小段。折叠盒、音频、imagemap、链接和文字选中在命中带外保持原行为，细节见[工作台说明](workbench.md#预览扫描线与源码行联动) |
| 无锚点的源码行 | 只给有可见输出的行建锚点，其余源码行扫描时会落到上一个锚点；折叠盒隐藏内容在展开并重新测量前不参与映射 |
