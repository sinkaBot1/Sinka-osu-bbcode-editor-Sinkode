# 桌面工作台说明

本文记录当前工作台行为。已知限制见[范围与已知限制](roadmap.md)。

## 布局与原文边界

- 桌面端编辑器与预览并排，各自独立纵向滚动；顶栏和模板侧栏固定，帮助面板独立滚动。
- 顶栏固定 56px 单行，底色并入框架面，只留一条 1px 下边线；面板头 40px（窄屏模板抽屉入口为 44px 触控方块时会被撑到 44），编辑器工具栏 44px，状态栏 26px；顶栏 + 面板头 + 工具栏合计 140px（窄屏为 144px）。极窄屏（≤359px）顶栏只保留品牌符号，避免换行改变高度。
- 开合把手贴在顶栏右下角，收起后顶栏高度归零，把手仍可点开；面板头右侧预留 70px，桌面落在预览面板头，单列时落在编辑器面板头。预览面板头的源码行指示线开关落在预留区左缘，右缘距面板右缘 70px，不与把手命中区重叠。
- 编辑与模板分隔线支持指针和键盘调整。编辑比例 30%–70%，方向键每次 1%；模板宽度 160–360px，诊断面板高度 72px–75vh，方向键每次 10px；实际范围受容器尺寸约束并通过 ARIA 暴露。分隔条悬停显示 2px 强调色细线加 4px 中性淡浮层，诊断面板顶部 12px 抓取条悬停显示 2px 中性横线。
- 预览正文最大宽度 890px；图片保持比例并随容器缩放，不裁切。布局测试覆盖 800×600、820×700、1024×768、1440×900 和 2560×1000。
- 800px 及以下使用模板抽屉；820px 起使用固定模板侧栏。窄屏状态栏允许换行，高度 44px。
- 工具栏 17 个按钮 36×36 单行排列，图标 17px，与编辑正文同面、不画分组框，组间只用 1×16 斜线分隔；横向滚动条隐藏，只允许工具栏内部横向滚动，溢出时右侧出现渐变遮罩与「更多编辑操作」按钮，浮层按组列出被裁掉的按钮。无选区时插入标签，有选区时包裹文本；可赋值标签定位到参数位置。编辑修改使用 CodeMirror 事务并纳入撤销历史。
- 预览、诊断、高亮、自动保存、面板开合和窗口缩放不得修改编辑器原文。复制操作复制完整原文。
- 编辑器行号栏与编辑正文同面，不画右描边；行号取次级色（三种主题实测 5.13–6.23:1），当前行只把行号转正文色，正文当前行是 12% 中性浮层（1.28–1.34:1）。源码行指示线开启时，目标行号转强调文字色并保留 600 字重；被高亮块扫过的行号短暂转色后淡回，尾迹不加粗。
- 诊断面板与编辑面同面、不画上描边。行高 38px、直角，悬停是 9% 中性浮层，选中是危险色 8% 浮层加 2px 危险色左条，位置列写成「第 6 行 · 第 1 列」。问题数为 0 时面板不渲染，状态栏中的 24px 胶囊显示「未发现问题」。

## 界面语言与控件规格

本节是工作台外观的规范来源，取值来自 `src/app/scale.css` 的令牌；颜色随主题走，形状、尺寸、动效与层叠全局唯一。

- **面只有三级**：框架面 `--surface-chrome`（顶栏、面板头、状态栏）、编辑面 `--surface-inset`（工具栏、编辑正文、行号栏、诊断面板）、画布面 `--surface-canvas`（预览底）；只有真正浮起的内容使用 `--surface-content` 或 `--surface-overlay`。
- **线是稀缺资源**：只保留面板边界、浮层轮廓和节奏线三类，取值只用 `--color-border` 与 `--color-divider-strong`，输入框算第二类；扫描线是覆盖层上的功能线，不属于边框。除此之外不画边框。
- **尺寸只从令牌取**：空间、控件高度、行高、字号、字距、圆角、阴影、时长、层叠和线宽都取自 `src/app/scale.css`，新样式不写字面量，由 `npm run style:check` 守。仍有少量迁移占位，清单以 `npm run style:check` 为准。
- **内容族与仪器族的分界**：圆角只出现在内容与文档上，直角只出现在仪器与结构上。内容族含模板侧栏、模板行、模板操作菜单、主题弹层和抽屉，圆角为卡片 12、浮层 10、行与控件 8，只允许浮层与抽屉使用投影；仪器族含顶栏、编辑器面板头与工具栏、编辑正文、状态栏、诊断面板、预览面板头与画布外框、帮助面板，圆角 0，胶囊 999，一律不用投影。浮层跟随触发者家族，主题弹层按既有决定并入内容族；`--r-row` / `--r-overlay` / `--r-card` 只允许出现在内容族选择器内。`CopyButton` 归仪器族。
- **斜切只有三个落点**：工具栏组间 1×16 斜线（`--skew-rhythm`）、顶栏开合把手的 `clip-path` 梯形、帮助行选中的 3px 竖条（`--skew-state`）。结构线正交，节奏线斜切，斜切不用在容器上。

**状态表达**

| 状态 | 表达 |
| --- | --- |
| 悬停 | 9% 中性浮层 + 文字转正文色，不改描边 |
| 选中/活动 | 7–8% 强调浮层 + 左竖条（内容族 2px 圆头，仪器族 3px 斜切，诊断行 2px 圆头危险色） |
| 键盘焦点 | 2px 强调色 + 2px 外扩 |
| 按下 | 9% → 16% 中性浮层，或 97% 缩放 |
| 禁用 | 次级色 + `not-allowed`，不只降不透明度 |
| 错误 | 危险色文字/图标 + 8% 危险色浮层 + 左竖条，不用纯红底白字 |

**无障碍底板。**

- 文字对比度 ≥ 4.5:1。
- 焦点环 2px、可见、不被遮挡。
- 顶栏动作、菜单项、内容族行 ≥ 44px；仪器族列表行满足 WCAG 2.2 AA 的 24px 下限；编辑器工具栏 36×36 与模板行是登记过的例外。
- `role`、`aria-expanded`、`aria-live`、`inert` 与焦点路径不因视觉变化而改变。

## 预览扫描线与源码行联动

- 预览面板头右侧、开合把手预留区内有一个 28px 高的 `ScanLine` 图标加文字开关，默认关闭；图标 16px，文字 12px「行指示线」，取完整名称的末四字，保证可见标签包含在无障碍名称里。
- `aria-pressed` 表达状态，中文 `aria-label` 与 `title` 为“显示源码行指示线”；静止取次级色、无框，未开启时悬停转正文色并加 `--state-hover` 中性浮层，开启后转强调文字色并加 `--state-selected` 强调浮层，指针停留也保持强调态。预览为空时按钮禁用，线、编辑器高亮与行号读数都不渲染。
- 开关状态与线的垂直比例写入 IndexedDB 工作区设置；第一次开启取 50%，之后恢复上次比例（0–1，非法值回落默认），切换模板保留开关与比例。
- 线是横穿预览视口的 1px `--color-accent` 实线，覆盖画布左右留白；两端是 6×6 实色强调小方块，无图标、直角、无阴影，外围有 24×24 透明命中区。
- 线体与端点都可拖，线体有 8px 透明命中带；悬停、拖动或键盘聚焦时显示「第 N 行」微标签，`cursor: ns-resize`。线固定在预览画布视口内，不随内容滚动；覆盖层不进入滚动内容，层叠低于 imagemap 悬停气泡、高于预览正文，滚轮落在命中带上时转发给画布，不拦截命中带以外的点击。
- 位置换算：线在视口中的比例换算成预览内容坐标，取「起点 ≤ 该高度」的最后一行锚点；同一 y 取行号较大者，在第一行之上取第一行，在最后锚点之下取最后一个锚点。
- 编辑器在目标行绘制整行强调块与 2px 左侧强调竖条，行号转 `--color-accent-text`，底色取 `--editor-indicator-line`，三主题取值与对比度见[主题与切换动效](theme.md#6-对比度复核)。拖动或键盘换行时高亮块在行间滑动 200ms，扫过的行号短暂亮起后淡回；目标行在视野外时编辑面同时用 200ms 缓动滚到目标行；编辑正文与主题切换保持瞬时，低动态效果下全部即时。
- 拖动、键盘移动或滚动预览时，编辑器用最近距离把目标行滚入视野，上下各保留 24px；滚动按 `--dur-2` 的 `--ease-scroll` 缓动播放，连续移动时续接同一个 200ms 时间轴、只更新目标行。用户操作编辑器时立即接管并取消未完成的滚动；滚动不改变光标、选区和撤销历史，最近 600ms 内发生过编辑时只更新高亮、不自动滚动。首次开启、切换模板或整篇替换文档时只应用高亮，不自动滚动。
- 键盘：线可聚焦；`↑` / `↓` 移动 1px，`Shift + ↑` / `Shift + ↓` 移动 10px，`PageUp` / `PageDown` 移动四分之一视口，`Home` / `End` 到第一个/最后一个锚点行，`Esc` 把焦点交还面板头开关。线容器使用 `role="slider"`、`aria-orientation="vertical"`、`aria-valuemin=1`、`aria-valuemax=文档行数`、`aria-valuenow=当前行`、`aria-valuetext="第 N 行"`。
- 开启时面板头常驻「第 N 行」，与「已更新/渲染中」并排；连续滚动不播报，只在键盘移动和拖动结束时通过隐藏的 `aria-live="polite"` 区域播报。窄屏（≤800px）预览面板头收回 70px 预留并隐藏预览状态文字。
- 锚点只覆盖有可见输出的源码行：文本行、输出 `<br>` 的空行、块级标签行和媒体行。纯结束标签行、末尾空行、被块级边界吸收的空行不建锚点；折叠盒隐藏内容在展开并重新测量前跳过；音频播放器内部会变化的计时文字不参与文本索引；同一选择器的块与媒体按 DOM 顺序定位。已知限制见[范围与已知限制](roadmap.md)。

## 顶栏、模板与焦点

- 顶栏提供帮助、主题和开合入口，以及指向项目仓库的 GitHub 标志入口。项目图标和字标使用主题强调色，随主题切换；入口无边框、无静止底色，品牌符号 46px、字标 92px，动作文字 13px 取次级色、悬停转正文色并显示 9% 中性浮层；GitHub 标志悬停不改色。动作入口保持 44×44 命中区，浮层只覆盖 34px 高的视觉范围。
- 键盘焦点环由一条全局规则提供：2px 强调色加 2px 外扩，覆盖工作台各容器（含 Teleport 到 body 的模板操作菜单与抽屉）。局部例外四处：品牌入口外扩 4px；模板菜单条目与编辑器工具栏按钮、溢出条目用 2px 内缩；输入框在获得焦点时（鼠标点击也算）都显示描边与焦点环。
- 模板列表采用平铺行。模板栏整体是一块浮起的内容卡片：四周留 8px 边距（右侧 2px，加上分隔条那一列，与编辑面之间共 10px），12px 圆角、1px 轮廓线，底色比框架面亮一档，卡片边缘就是与编辑面的分界，不画竖线。标题行是 13px/600 的「模板」加等宽计数，右侧是 24×24 的批量选择、新建与开合按钮；行高 34px、8px 圆角、13px 文字，选中态是强调浮层加 2px 圆头竖条。页脚「恢复默认示例」高 32px。更多菜单提供重命名、复制和删除，重命名与删除确认在对应行展开；删除最后一个模板时自动创建空模板，恢复示例只新增模板。
- 模板操作菜单是内容族浮层：10px 圆角、有投影、项高 32px、12px 文字、15px 图标；帮助面板是仪器族浮层（直角、无投影）。重命名输入框 32px 高、8px 圆角，静止是结构线，获得焦点才转强调色并加 2px 焦点环；删除确认保留左侧 2px 危险色竖条，不铺红底。桌面端点击目标小于 44px（行 34、菜单项 32），窄屏抽屉里这三类控件都保持 44px。
- 菜单支持键盘操作、Esc 和外部点击关闭，并把焦点恢复到触发按钮；最窄模板栏中菜单和确认按钮仍需可见、可操作。
- 保存和复制均显示成功或失败反馈。复制成功后按钮就地显示对勾和「已复制」约 2 秒，失败原因显示在按钮下方。自动保存不创建撤销记录，切换模板会清空文本历史。

### 模板批量删除

模板栏只有三个状态：
- 普通态：标题「模板」加等宽计数，标题右侧是批量选择与新建两个 24×24 图标按钮，行尾是「更多」，页脚是「恢复默认示例」。
- 选择态：标题改为「已选 N 项」（数字等宽），标题右侧只剩文字按钮「取消」，每行是一个整行复选按钮，页脚左侧「全选 / 取消全选」、右侧「删除 N 项」（最窄栏宽下改为上下两行）。
- 确认态：标题「确认删除」，列表只保留所选模板、保持原顺序并滚到顶部，行不可点、不再有尾部图标，页脚是一行「此操作不可撤销。」加一个占满宽度的删除按钮。
- 入口只有一个：标题行的 `ListChecks` 批量按钮，桌面侧栏与窄屏抽屉共用，始终可用（只有 1 个模板时也能进入）。桌面 24×24，窄屏抽屉 44×44；`aria-label` 与 `title` 为「批量选择模板」。
- 转场：普通 → 选择点批量按钮；选择 → 确认点「删除 N 项」，仅 N > 0 时可用；确认 → 选择点「取消」或 Esc；选择 → 普通点「取消」或 Esc；删除成功回普通态并清空勾选，失败留在确认态。关闭抽屉或收起侧栏重置到普通态并清空勾选。当前模板可勾选、可删除；删除后活动模板取剩余列表的第一个（按 `createdAt` 升序），没有剩余时数据层创建空白模板（「未命名模板」、空内容）。删除前先冲刷待保存内容，删除在单个 IndexedDB 事务里完成，要么全删要么全不删；批量删除没有撤销和回收站。本地存储不可用时按单删语义从内存移除所选并兜底活动模板，状态栏继续显示不可用，界面按删除成功退出选择态。
- 键盘与朗读：勾选支持点击整行、Space 或 Enter，`aria-checked` 同步，不连续选中同样合法；全部选中后页脚改为「取消全选」，再点清空；部分选中仍显示「全选」，点击补全。Tab 顺序是标题「取消」→ 各行复选 → 页脚「全选」→「删除 N 项」；Esc 分层回退（确认 → 选择 → 普通），选择态与确认态下 Esc 不关闭抽屉。焦点落点：进入选择到第一行复选标记，进入确认到标题「取消」，取消确认回「删除 N 项」，退出选择与删除成功回批量按钮。常驻的隐藏 `role="status"` 区只在进入选择、进入确认、删除成功时各播报一次，逐项勾选不额外播报；删除失败用 `role="alert"` 显示「删除失败，请重试」，勾选与列表不变，可原地重试。
- 尺寸：桌面行高 34、复选标记视觉 16×16（圆形，命中区 24）、页脚按钮 32 高 12px 字、标题文字按钮 24 高 12px 字，三态行文字与行高一致（13px / 34px）；窄屏抽屉里行与页脚按钮都是 44，复选标记命中区也是 44。最窄栏宽（面板 < 150px，约对应 206px 以下的模板栏）启用紧凑排版：批量态标题降为 11px，选择态页脚改成「全选 / 取消全选」与「删除 N 项」上下两行、各占满宽度；其余栏宽下两者同一行，两种排法都不换行、不裁切。面板宽度用容器查询读取，与视口宽度无关。
- 视觉与动效：选中行取强调浮层，当前模板保留 2px 圆头竖条；复选标记未选中是 1px 次级色描边圆圈，选中是强调色实底加 `Check`；确认页删除按钮用 15px `Trash2` 与危险色文字，选择页页脚只留文字按钮，禁用时次级色加 `not-allowed`。确认态的错误行是危险色文字加 `role="alert"`，不铺红底。复选标记与行浮层用 `--dur-1`；三态切换时标题、列表与页脚作为一整块用 `--dur-2` 淡入并上移 6px，旧块即时移除，焦点落点与滚到顶部在同一帧落到新节点；首次展开侧栏不播放切换动画，低动态效果下即时。

## 帮助与主题

- 帮助内容是固定中文参考，标签定义以 `tagRegistry` 为准；可搜索、筛选分类、展开说明和复制示例，示例使用项目安全兼容管线，不会自动写入编辑器。关闭后焦点返回帮助入口；图片示例使用本地素材，音频和 YouTube 示例不加载第三方媒体。
- 帮助面板是仪器族浮层：贴右边缘、宽 380、直角无投影，只保留左外轮廓一条线，头部、搜索区、列表与详情之间不画分隔线。头部 56px，搜索框直角、分类是胶囊、列表行 38px、标签列 74px，选中行加强调浮层与 3px 斜切竖条，详情块用内嵌面，其余字号、字距、圆角与阴影从 `src/app/scale.css` 取。搜索或筛选没有结果时，列表位置换成空状态：左对齐，自上而下是 24×2 的节奏线色斜切短线、微标签与一行 12px 解释，文字取次级色；不画描边、不放图标、不放动作按钮，解释直接告诉用户换关键词或切回「全部」，容器带 `role="status"`。预览画布的空占位仍是一行“输入 BBCode 后，预览将在这里显示。”，不并入空状态样式。
- 主题菜单提供当前三套主题（定义见[主题与切换动效](theme.md)第 1 节）；选择写入 IndexedDB 并同步至文档根 `data-theme`，重新打开菜单时焦点位于当前主题，Esc 或外部点击关闭后焦点返回触发按钮。色板各自显示对应主题的背景、正文和强调色；每个主题块声明完整令牌，预览样式通过 `--preview-*` 令牌随主题切换。主题弹层是内容族浮层（12px 圆角、1px 轮廓、`--elevation-content` 投影），宽 360px（窄屏 `100vw - 24px`），选项高 44px、8px 圆角，选中态是强调浮层加 2px 圆头竖条和勾选；色板 40×22、8px 圆角且描边向内画，说明文字 11px、最多两行、不用省略号截断。
- 主题切换从顶栏主题按钮开始圆形揭示，时长与降级规则见[主题与切换动效](theme.md)第 4 节。窄屏模板抽屉是内容族：右侧上下 12px 圆角、底色并入内容卡片面、保留侧向 `--shadow-drawer` 投影，头部 56px 且不画色带与下描边，关闭按钮视觉 24px、命中区 44px，入场位移 16px；遮罩层级低于模板操作菜单。

## 动效

- 时长只有四档：`--dur-1` 120ms（悬停、按下、颜色）、`--dur-2` 200ms（状态切换、行内展开）、`--dur-3` 260ms（面板开合、浮层进入）、`--dur-exit` 160ms（退出，约为进入的 62%）；缓动统一为 `--ease`（`cubic-bezier(0.22, 1, 0.36, 1)`）。
- 唯一例外是编辑器跟随指示线的长距离滚动，使用 `--ease-scroll`（`cubic-bezier(0.45, 0, 0.2, 1)`）：两端更慢，把 200ms 的位移均匀展开，避免大跨度时首帧吃掉大半距离。主题圆揭示是独立设置项（0–5000ms），不并入这四档。
- 帮助、主题进入为 260ms，退出为 160ms；帮助详情展开为 260ms，收起为 160ms；帮助面板跟随顶栏开合，边缘过渡保持对齐。低动态效果模式缩短工作台过渡，不改变焦点、滚动、状态反馈或编辑器原文；`scale.css` 已把四档时长覆盖为 0.01ms。
- 复制按钮按下时缩至 97%，复制成功后对勾和文案淡入，低动态效果下即时切换。
- 预览折叠盒与 imagemap 提示气泡的时间和交互属于兼容性行为，规则见[兼容性说明](compatibility.md)。
