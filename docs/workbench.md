# 桌面工作台说明

本文记录当前工作台行为。未完成事项和已知限制见[路线与已知限制](roadmap.md)。

## 布局与原文边界

- 桌面端编辑器与预览并排，各自独立纵向滚动；顶栏和模板侧栏固定，帮助面板独立滚动。
- 顶栏固定 56px 单行，底色并入框架面，只保留一条 1px 下边线；开合把手是贴在顶栏右下角的梯形签，收起后顶栏高度归零，把手仍可点开。面板头 40px（窄屏的模板抽屉入口为 44px 触控方块时会被撑到 44），编辑器工具栏 44px，状态栏 26px；顶栏 + 面板头 + 工具栏合计 140px（窄屏模板入口撑高面板头时为 144px）。极窄屏（≤359px）顶栏只保留品牌符号，避免换行改变高度。
- 开合把手占据顶栏右下角时，面板头右侧预留 70px（46px 足迹 + 16px 右距 + 8px 间距）；桌面落在预览面板头，单列时落在编辑器面板头。不再使用按视口宽度补偿定位的写法。
- 编辑与模板分隔线支持指针和键盘调整。编辑比例范围为 30%–70%，方向键每次调整 1%；模板宽度为 160–360px，诊断面板高度为 72px–75vh，方向键每次调整 10px。实际范围受容器尺寸约束，并通过 ARIA 暴露。
- 预览正文最大宽度为 890px；图片保持比例并随容器缩放，不裁切。桌面布局测试覆盖 800×600、820×700、1024×768、1440×900 和 2560×1000。
- 800px 及以下使用模板抽屉；820px 起使用固定模板侧栏。窄屏实现不构成移动端支持承诺。
- 工具栏的 17 个按钮 36×36 单行排列，图标 17px，与编辑正文同面、不画分组框，组间只用 1×16 的斜线分隔；横向滚动条隐藏，只允许工具栏内部横向滚动，溢出时右侧出现渐变遮罩与「更多编辑操作」按钮，浮层按组列出被裁掉的按钮。无选区时插入标签，有选区时包裹文本；可赋值标签定位到参数位置。编辑修改使用 CodeMirror 事务并纳入撤销历史。
- 预览、诊断、高亮、自动保存、面板开合和窗口缩放不得修改编辑器原文。复制操作复制完整原文。

## 顶栏、模板与焦点

- 顶栏提供帮助、主题和开合入口，以及指向项目仓库的 GitHub 标志入口。项目图标和字标使用主题强调色，随主题切换；顶栏操作入口无边框、无静止底色、46px 宽的品牌符号加 92px 字标，动作文字 13px 取次级色、悬停转正文色并显示 9% 中性浮层；GitHub 标志悬停不改色；键盘焦点显示 2px 主题色焦点环。动作入口保持 44×44 命中区，浮层只覆盖 34px 高的视觉范围。
- 模板列表采用平铺行。模板栏整体是一块浮起的内容卡片：四周留 8px 边距（右侧 2px，加上分隔条那一列，与编辑面之间共 10px），12px 圆角、1px 轮廓线，底色比框架面亮一档，卡片边缘本身就是与编辑面的分界，不再画竖线。标题行是 13px/600 的「模板」加等宽计数，右侧 24×24 的新建与开合按钮。行高 34px、8px 圆角、13px 文字，选中态是强调浮层加 2px 圆头竖条（仪器族的帮助行用 3px 斜切条、主题选项用 3px 直条，三者是刻意的差异）。页脚「恢复默认示例」高 32px，与行同语言。更多菜单提供重命名、复制和删除；重命名与删除确认在对应行展开。删除最后一个模板时自动创建空模板；恢复示例只新增模板。
- 模板操作菜单是内容族浮层：10px 圆角、有投影、项高 32px、12px 文字、15px 图标；帮助面板仍是仪器族浮层（直角、无投影），主题弹层按项目所有者裁决并入内容族，规格见下一条。重命名输入框 32px 高、8px 圆角，静止是结构线，获得焦点才转强调色并加 2px 焦点环；删除确认保留左侧 2px 危险色竖条，不铺红底。桌面端点按目标小于 44px（行 34、菜单项 32），窄屏抽屉里这三类控件都保持 44px。
- 菜单支持键盘操作、Esc 和外部点击关闭，并把焦点恢复到触发按钮。最窄模板栏中菜单和确认按钮仍需可见、可操作。
- 保存和复制均显示成功或失败反馈。复制成功后按钮就地显示对勾和“已复制”约 2 秒；复制失败原因显示在按钮下方。自动保存不创建撤销记录，切换模板会清空文本历史。

## 帮助与主题

- 帮助内容是固定中文参考，标签定义以 `tagRegistry` 为准。帮助可搜索、筛选分类、展开说明和复制示例；示例使用项目安全兼容管线，不会自动写入编辑器。
- 帮助面板是仪器族浮层：贴右边缘、宽 380、直角无投影，只保留左外轮廓一条线，头部、搜索区、列表与详情之间不画分隔线。头部 56px，标题 13px/600 加一行 11px 说明（点击标签查看语法、效果与常见错误，原文问题见诊断区），关闭按钮 28px 无描边。搜索框 32px 直角、获得焦点转强调色并加 2px 焦点环；分类是 24px 胶囊，静止为中性浮层、选中为强调浮层加 600 字重。列表行 38px、标签列 74px，行不画线，悬停加中性浮层，选中加强调浮层与 3px 斜切竖条；展开的详情块用内嵌面，写法框只留 1px 轮廓，小标题是 10.5px/600/0.2em 的微标签，“复制示例”28px 无描边。搜索或筛选没有结果时，列表位置换成空状态：左对齐、顶部 24px 内边距，自上而下是 24×2、取节奏线色的斜切短线、10.5px/600/0.2em 的微标签与一行 12px 解释，文字取次级色；不画描边、不放图标、不放动作按钮，解释直接告诉用户下一步怎么做（换关键词、切回“全部”分类）。空状态容器带 `role="status"`，读屏能知道结果变空了。预览画布的空占位仍是一行“输入 BBCode 后，预览将在这里显示。”，不并入空状态样式。
- 帮助面板独立滚动。关闭面板后焦点返回帮助入口。图片示例使用本地素材，音频和 YouTube 示例不加载第三方媒体。
- 主题菜单提供 `Darkode`（深色，默认）、`Claucode`（浅色）和 `Hollowcode`（深色，近纯黑底和琥珀金强调色）。选择写入 IndexedDB，并同步至文档根 `data-theme`；重新打开菜单时焦点位于当前主题，Esc 或外部点击关闭后焦点返回触发按钮。
- 主题菜单色板各自显示对应主题的背景、正文和强调色。每个主题块必须声明完整令牌，预览样式通过 `--preview-*` 令牌随主题切换。主题弹层是内容族浮层，与模板栏同族：12px 圆角、1px 轮廓、`--elevation-content` 投影，底取 `--surface-overlay`；宽 360px（窄屏取 `100vw - 24px`），内边距 12px；标题 13px/600 加 24px 圆角无描边关闭按钮；选项高 44px、8px 圆角，选中态是强调浮层加 **2px 圆头竖条**（与模板行同源）和勾选；色板 40×22、8px 圆角且描边向内画；说明文字 11px、最多两行，不用省略号截断。
- 主题切换从顶栏主题按钮开始圆形揭示。时长由 `themeRevealDuration` 提供，默认 900ms，范围为 0–5000ms；不支持动画、开启低动态效果、时长为 0 或无法获取按钮位置时直接切换主题。
- 窄屏模板抽屉是内容族：右侧上下 12px 圆角、底色并入内容卡片面、保留侧向投影，头部 56px 且不画色带与下描边，关闭按钮视觉 24px、命中区 44px，入场位移 16px。遮罩层级低于模板操作菜单，菜单永远盖在抽屉之上。

## 动效

- 工作台统一缓动曲线为 `cubic-bezier(0.22, 1, 0.36, 1)`。顶栏和模板侧栏开合为 260ms；帮助、主题进入为 260ms，退出为 160ms；帮助详情展开为 260ms，收起为 160ms。退出时长取 `--dur-exit`，约为进入的 62%。
- 帮助面板跟随顶栏开合，边缘过渡保持对齐。低动态效果模式缩短工作台过渡，不改变焦点、滚动、状态反馈或编辑器原文。
- 复制按钮按下时缩至 97%，复制成功后对勾和文案淡入；低动态效果模式使用即时状态。
- 预览折叠盒与 imagemap 提示气泡的时间和交互属于兼容性行为，规则见[兼容性说明](compatibility.md)。
