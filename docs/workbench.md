# 桌面工作台现行说明

> 状态：已验收（2026-10-02）。来源为已实现的工作台交互及项目所有者“人工测试全部正常”的确认。
> 本文提炼持续维护的交互规则；历史实现与测试记录不随本仓库发布。视觉截图基线、跨浏览器矩阵与 axe 审计的排期见[路线与已知限制](roadmap.md)。

## 布局与原文边界

- 第一版承诺桌面工作台：编辑与预览并排、独立纵向滚动；顶栏和模板侧栏位置固定，帮助独立滚动。
- 桌面分隔线支持指针和键盘。编辑比例范围为 30%–70%，方向键步进 1%；模板宽度 160–360px、诊断高度 72px–75vh，方向键步进 10px；实际范围叠加容器约束，并通过 `aria` 暴露。
- 预览正文最大宽度为 890px；图片保持比例，不能因面板变窄而静默裁切。桌面视口验收覆盖 800×600、820×700、1024×768、1440×900、2560×1000。
- 当前 800px 边界仍使用已有模板抽屉，820px 恢复固定模板侧栏；这是现状记录，不能据此扩大为移动端支持承诺。
- 工具栏 17 个按钮单行平铺；仅工具栏内部可横向滚动。无选区时插入标签，有选区时包裹，可赋值标签定位空参数；所有修改共用 CodeMirror 事务与撤销规则。
- 预览、诊断、高亮、自动保存、面板开合与窗口缩放均不得反向修改原文；复制使用当前编辑器完整原文。

证据：[布局测试](../tests/e2e/layout.spec.ts)、[编辑器测试](../tests/e2e/editor.spec.ts)、[模板测试](../tests/e2e/templates.spec.ts)；桌面闭环的人工验收结论为 2026-10-02 项目所有者确认（记录不随本仓库发布）。

## 顶栏、模板与焦点

- 顶栏提供帮助、主题及开合入口，动作区最左侧另有指向项目 GitHub 仓库的官方标志入口。三个入口都是无框样式：静止无边框无底色，悬停浮出 9% 中性浮层（圆角 5px）、过渡 120ms，与编辑器工具栏同一种语言；动作区左端有一根 `1px × 26px` 的装饰性休止符，把品牌区与操作区分开，不参与 Tab 顺序。约定与裁定理由见[图标规范 §7.4](ui-icon-system.md#74-顶栏动作区的无框约定2026-10-03-所有者裁定)。品牌、可访问名称和素材边界见同一文档。收起入口退出焦点与辅助技术读取，开合按钮仍可操作。
- **悬停语言统一（2026-10-03）**：项目所有者指出"悬停交互多会显示蓝框"后，把顶栏的无框口径铺到整个工作台——悬停一律只加中性背景浮层，不改描边颜色；强调色只留给"选中 / 活动"和键盘焦点环。令牌、逐处取值与不在范围内的项见[图标规范 §8](ui-icon-system.md#8-工作台悬停与状态色2026-10-03-所有者要求)，禁止回退的自动化断言见[模板端到端测试](../tests/e2e/templates.spec.ts)。
- 顶栏品牌标志（图形标志加字标）同时是指向项目所有者 osu! 主页的链接，新标签页打开并带 `rel="noopener noreferrer"`；其地址、配色与可访问名称规则见[图标规范 §6.2](ui-icon-system.md#62-品牌素材)。
- 模板列表采用平铺行，当前模板有明确选中状态。更多菜单提供重命名、复制、删除；重命名和二次删除确认在对应行下方展开，取消不执行删除。
- 菜单支持键盘、Esc 和外部点击关闭；焦点按现有触发按钮路径恢复。最窄模板栏中，菜单和确认按钮仍需可见、可操作。
- 新建、切换、重命名、复制、删除和恢复示例保持既有模板不变量；删除最后一个模板后补建空模板，恢复示例只新增。
- 保存和复制均有成功、失败反馈；复制成功反馈短暂显示约 2 秒。自动保存不创建撤销记录，模板切换清空文本历史。

证据：[顶栏测试](../tests/e2e/header.spec.ts)、[模板组件测试](../tests/unit/templates-ui.test.ts)、[模板测试](../tests/e2e/templates.spec.ts)。

## 帮助与主题

- 帮助为固定中文参考，以 `tagRegistry` 为标签唯一来源；不随光标变化、不将示例自动写入编辑器。
- 打开后焦点进入搜索；可搜索、筛分类、展开详情和复制示例。详情位于对应条目下方，再次点击收起，切换条目关闭旧项；展开项被筛掉后关闭，不自动恢复。
- 帮助独立滚动；Esc 或关闭按钮关闭后焦点回到帮助入口。效果示意通过项目安全兼容管线渲染，折叠与热区可操作；图片使用项目自制本地素材，音频与 YouTube 为示意，不加载第三方媒体。
- 主题为锚定菜单，当前仅 `Darkode`（主题 ID `darkode`，2026-10-03 由 `vscode-dark` 更名）；点击写入 `selectedThemeId` 并由 `App.vue` 同步到文档根的 `data-theme`，刷新回显。Esc 或外部点击关闭并恢复触发按钮焦点。
- 工作台及语法高亮复用语义令牌，预览保持项目自有深色主题。配色按主题块组织：`theme.css` 中每个主题是一个 `[data-theme='…']` 块，声明整套 shell 配色与 `--preview-*` 预览语义色；预览组件只引用令牌，新增主题不必改组件。`theme.css` 的 `:root` 保留 Darkode 的兜底副本，供主题属性缺失的首帧与脱离主题挂载的组件使用。配色调整仍遵守[兼容性 §6.4](compatibility.md#64-预览配色裁决与块级外边距待决项2026-09-25)的所有者授权要求。

证据：[帮助测试](../tests/e2e/help.spec.ts)、[帮助内容一致性](../tests/unit/help-content.test.ts)；2026-10-01 的主题人工测量与帮助面板复查结论见开发过程记录（不随本仓库发布）。

## 动效与持续维护

- 工作台面板沿用 `cubic-bezier(0.22, 1, 0.36, 1)`；顶栏、模板侧栏开合为 260ms，帮助和主题进入 260ms、退出 180ms；帮助详情展开 260ms、收起 180ms。
- 帮助面板打开时，顶栏开合同时带动面板上边缘：面板 `top` 与顶栏高度同为 260ms、同一曲线，过渡期间两者边缘保持对齐，不再瞬间跳位；帮助进入动画尚未结束时收起顶栏同样跟随。
- 低动态效果模式缩短过渡；焦点、滚动、状态反馈和原文保持不受动效影响。
- 预览折叠盒的 400ms 动效属于兼容性行为，不能随工作台动效一并修改；规则见[兼容性说明](compatibility.md)。
- [编辑器字体](editor-font.md)和[图标规范](ui-icon-system.md)是现行文档；早期的视觉中间稿不随本仓库发布，也不作为最终规范。
- 尚未完成的工作、待裁决项与移动端后续版本范围见[路线与已知限制](roadmap.md)。
