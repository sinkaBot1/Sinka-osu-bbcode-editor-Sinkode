# 编辑器字体记录

> 记录日期：2026-10-01

## 决策

CodeMirror 编辑区采用 IDE 常见的等宽字体栈：`JetBrains Mono`、`Cascadia Code`、`Consolas`、系统等宽字体。编辑区固定使用 `14px` 字号和 `1.6` 行高，行号、补全菜单与正文保持同一字体语境；数字启用等宽数字，避免光标移动或统计内容变化时发生宽度跳动。

该调整只作用于编辑器和补全菜单，不改变预览正文的 `Inter` 字体、颜色令牌、BBCode 原文或预览结果。字体未安装时由浏览器按顺序选择可用回退字体，不下载远程字体。

## 固定验收样例

```text
[b]标签[/b] = 0123
```

在 Chromium `1280 × 800` 视口中打开编辑器，`.cm-content` 和 `.cm-gutters` 的计算字号应为 `14px`，编辑正文的计算字体栈应包含 `JetBrains Mono`，补全菜单使用同一字体栈。自动化证据见 `tests/e2e/editor-typography.spec.ts`。

## 依据

- 编辑区使用等宽字体并显示左侧行号（第一版需求条款 §6.1）。
- 工作台优先使用 Cascadia Code、中文使用 Microsoft YaHei UI（早期视觉中间稿 §2.2，该稿不随本仓库发布）。
- 本次改动将 IDE 字体优先级收敛到编辑器局部，保留现有工作台和预览字体边界。
