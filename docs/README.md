## 本目录不含什么

- 按阶段划分的实施与验收记录、历史测量页面和截图：保存在本机，不随本仓库发布。
- 开发前请先读[协作规则](../AGENTS.md)；现行范围、待办与优先级见[路线与已知限制](roadmap.md)。
- 因此部分文档里会出现“阶段 N”或具体日期的表述，那是历史证据的来源标注，不代表本仓库还有对应的阶段文档；结论本身以该文档正文为准。

## 文档维护约定

- 任何行为改动先落到文档与固定样例，再改实现；文档与实现不一致时，先更新文档再报告完成。
- 新增或修改兼容行为时，必须同步更新[兼容性说明](compatibility.md)第 6 节的差异表，以及对应固定样例 `metadata.json` 中的差异说明。
- 配色按主题块组织，提供深色 `Darkode`、浅色 `Claucode` 与深色 `Hollowcode`（近纯黑底配琥珀金强调色）三套主题；新增配色、改动色值或调整透明度前必须先取得项目所有者授权（见[主题与切换动效](theme.md)与[兼容性说明 §6.4](compatibility.md#64-预览配色裁决与块级外边距待决项2026-09-25)）。
- 提交前跑完六条固定命令（见[测试说明](testing.md#3-六条固定命令)），并运行 `npm run docs:check` 校验本文档目录内所有 Markdown 的链接与锚点。
