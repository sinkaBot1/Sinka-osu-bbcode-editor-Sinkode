# 文档入口

第一次接触项目请先读[项目说明](../README.md)。本文档按用途列出当前有效的开发与维护资料。

## 按任务找文档

| 任务 | 文档 |
| --- | --- |
| 了解项目、安装和常用命令 | [项目说明](../README.md) |
| 了解隐私、数据保存和外部请求 | [隐私说明](../PRIVACY.md) |
| 修改解析、诊断或预览行为 | [兼容性说明](compatibility.md)、[测试说明](testing.md) |
| 修改工作台、主题、图标或字体 | [工作台说明](workbench.md)、[主题与切换动效](theme.md)、[图标规范](ui-icon-system.md)、[编辑器字体](editor-font.md) |
| 新增测试或固定样例 | [测试说明](testing.md) |
| 查看范围、限制和待办 | [路线与已知限制](roadmap.md) |
| 查看协作和安全规则 | [协作规则](../AGENTS.md) |

## 文档分类

- **项目说明**：面向使用者和首次参与开发者。
- **兼容性说明**：锁定的 osu-web 基准、可观察行为、固定差异和证据路径。
- **测试说明**：测试分层、固定命令、固定样例格式和离线隔离要求。
- **工作台、主题、图标、字体说明**：当前实现需要保持的界面规则。
- **路线与已知限制**：当前范围、待裁决事项、已知限制和后续计划。
- **`docs/evidence/`**：可复查的截图、测量脚本和专项证据；README 说明证据对应的行为与复查方法。

## 维护规则

- 该写什么、不该写什么，见[协作规则](../AGENTS.md#文档与实现)，这里不再重复。
- 修改兼容行为时，同步更新[兼容性说明](compatibility.md)差异表和对应固定样例的 `metadata.json`。
- 改完文档运行 `npm run docs:check`。
