# UI 图标系统

> 文档状态：现行图标规范（2026-10-02），已随第一版验收；实际接入状态见 §6。
> 适用范围：工作台 UI、编辑器工具栏、移动端导航、状态反馈和弹窗控件

## 1. 设计决定

第一版工作台 UI 采用 Lucide 的线性 SVG 图标作为快捷操作图标系统。图标用于提高工具栏和窄屏导航的识别速度，不能替代必要的文字说明、键盘操作或屏幕阅读器标签。

图标只服务于产品自己的工作台界面，不用于复制 osu-web 或 MOBE 的图标、样式和素材，也不改变预览区域的配色和视觉规则。

## 2. 来源与依赖

- npm 包：`@lucide/vue`
- 当前锁定版本：`1.41.0`
- 源码仓库：[lucide-icons/lucide](https://github.com/lucide-icons/lucide)，Vue 包位于 `packages/vue`
- 官方网站：[lucide.dev](https://lucide.dev)
- 包许可证：ISC
- 项目依赖记录：`package.json`、`package-lock.json`

图标通过 Vue 组件打包为本地 SVG，不在运行时从网络加载图片。新增或升级图标依赖必须继续使用 npm、HTTPS registry 和提交的 lockfile，并经过依赖变更审查。

## 4. 使用规则

### 4.1 视觉规则

- 采用单一线性图标风格，不混用 emoji、位图图标或其他图标库。
- 产品 UI 中默认尺寸为 `18px`–`20px`；触控按钮本身至少保留 `44px × 44px` 的可操作区域。
- 图标描边使用统一的 `stroke-width`，颜色读取主题令牌，不在组件中写入新的硬编码颜色。
- 图标只表达操作或状态，不使用装饰性插画填充工作区。
- 颜色不能作为唯一状态依据；错误、成功和保存状态同时提供文字或可读标签。

### 4.2 文字与标签规则

- 高频编辑操作可以使用图标按钮。
- 模板栏的新建、重命名和复制操作使用图标按钮；删除和恢复默认示例同时保留中文文字，避免重要操作只依赖图标。
- “颜色”“居中”“帮助”“主题”等容易产生歧义的功能，桌面端优先使用图标加文字，移动端使用图标加可见提示或分段控件。
- 每个图标按钮必须提供 `aria-label` 和 `title`；SVG 本身设置 `aria-hidden="true"`。
- 删除、恢复、确认等重要或有破坏性的操作必须保留文字，不允许只显示图标。

示例：

```vue
<button class="icon-button" type="button" aria-label="撤销" title="撤销">
  <Undo2 :size="18" aria-hidden="true" />
</button>
```

### 4.3 交互规则

- 图标按钮必须支持鼠标、键盘和触屏操作。
- `Tab` 焦点顺序应与界面阅读顺序一致，并保持可见焦点环。
- 弹窗、抽屉和帮助面板中的关闭图标必须支持 `Esc`。
- 拖动分隔线必须同时提供方向键调整方式，不能只依赖拖动图标。
- 悬停提示不能是唯一说明方式；触屏设备没有 hover 时，功能仍必须可理解和可操作。

## 5. 不在本决定范围内的内容

- Lucide 图标系统不负责生成产品 Logo、营销插画、背景纹理或用户卡片素材；顶栏品牌标志使用项目所有者提供的独立素材，见 §6.2。
- 不下载或复制 osu-web、MOBE 的图片、字体、图标和样式文件。
- 不使用远程图片 URL 作为工作台图标来源。
- 不为了使用图标库而修改 BBCode 解析、诊断、预览兼容规则。
- 品牌标志不属于 Lucide 图标系统：项目自有品牌素材见 §6.2，GitHub 官方标志见 §7.1，两者都按各自来源的原始形态使用。
- 不把图标系统扩展为第二套主题配色；主题颜色仍遵守[兼容性说明 §6.4](compatibility.md#64-预览配色裁决与块级外边距待决项2026-09-25)的所有者授权规则。

### 7.4 顶栏动作区的无框约定（2026-10-03 所有者裁定）

- 顶栏三个入口（GitHub 仓库、帮助、主题）统一为无框样式：静止时没有边框、没有底色，只有图形和文字；悬停浮出一层 `rgb(215 222 232 / 9%)` 中性浮层，过渡 `120ms ease`。这与编辑器工具栏按钮、模板行使用同一种语言。
- 裁定理由（含实测）：原实心底与头栏底对比度只有 `1.03:1`、1px 边框 `1.44:1`，这个"框"在视觉上几乎不成立，却把顶栏切成三个方块；去掉后同时消除了 §4.1 之外的一处低对比描边。
- 无框不等于降低可操作性：可操作区域仍是 `44px × 44px` 起（实测图标入口 44×44、文字入口 60×44），键盘焦点仍是 2px 主题色焦点环，窄屏仍整组换行且不溢出。
- `prefers-reduced-motion: reduce` 下该过渡缩短到 `0.01ms`，与顶栏开合动效一致。
- 悬停浮层与键盘焦点环都带 `border-radius: 5px`，与编辑器工具栏按钮同一半径；三个入口的内边距统一为 4px，同一组浮层外扩一致（2026-10-03 补充）。
- 动作区最左侧有一根功能休止符：`1px × 26px`、`rgb(215 222 232 / 16%)`，纯装饰、`aria-hidden="true"`、不参与 Tab 顺序。规格取自编辑器工具栏分隔线（同为 1px 宽、26px 高，不随 44px 可操作区拉满）；颜色比工具栏用的 `--color-border` 略强，因为头栏底比工具栏底亮，需要更大的分离度才能保持同级可见度（实测约 `1.5:1`，与中线两侧共同构成约 `3:1` 的边界）。它是本节的记录例外：不新增颜色令牌，也不因此改成强调色。
